# =============================================================================
# scripts/charon_manifest.txt
#
# Paths shared between this workspace and the `charon` template repo
# (https://github.com/Duke-Vascular-Informatics/charon). Each line is one
# path (file or directory), synced as a unit by scripts/pull_charon_updates.sh
# and scripts/push_charon_updates.sh. '#' starts a comment; blank lines are
# ignored; order doesn't matter.
#
# MAINTENANCE RULE: a directory listed here must contain ONLY generic,
# shareable content, forever. If a lab-specific file is ever added directly
# inside one of these directories (e.g. a new workspace-root script that
# hardcodes this lab's data), either move it elsewhere or demote this entry
# to individual file paths.
#
# Deliberately excluded (diverge by design, never synced):
#   docs/CHANGELOG.md, docs/MIGRATION_PLAN_REPO_SPLIT.md,
#   docs/REPORT_GENERATION.md, CITATION.cff, .github/CODEOWNERS,
#   studies.yaml, contributors.yaml, phenotype_library/catalog.yaml,
#   osf/osf_projects.csv, osf/osf_files.csv, WORKSPACE_ROSTER.md
# The four template submodules are updated via normal `git submodule`
# pointer bumps, not through this manifest.
# =============================================================================
